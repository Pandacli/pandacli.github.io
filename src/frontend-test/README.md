# 前端与移动端自动化测试

前端自动化测试按平台分为 **Android、HarmonyOS、iOS、Web** 四条线。每个平台的测试框架、驱动方式和工程化实践各不相同，本栏目分别整理各平台的自动化测试方案与实战经验。

- **Android**：Appium、UI Automator 等框架的 Android 端自动化测试。
- **HarmonyOS**：鸿蒙应用的自动化测试，如 Hypium 测试框架。
- **iOS**：XCUITest、Appium 等框架的 iOS 端自动化测试。
- **Web**：Playwright、Selenium、Cypress 等框架的 Web UI 自动化测试。
