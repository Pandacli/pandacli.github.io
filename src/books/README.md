# 推荐书籍

这里整理测试、开发、AI 等方向值得反复阅读的技术书籍，附带每本书的核心内容与阅读建议。

## 分类

- **软件测试**：测试理论、自动化测试、性能测试、测试管理等方向。
- **后端开发**：Java、数据库、分布式、系统设计等方向。
- **AI 与机器学习**：机器学习、深度学习、大语言模型等方向。

## 阅读建议

- 优先选择与当前工作直接相关的书籍，带着问题去读。
- 经典书籍值得反复阅读：第一遍建立框架，第二遍深入细节。
- 读完及时整理笔记，输出成博客文章效果更好。
