# Python 基础

本模块是 Python 学习的第一站，目标是快速掌握语言核心语法，能独立编写可运行的 Python 程序。文章均结合 **Java 语言对比** 讲解，帮助有 Java 基础的开发者快速迁移。

## 本模块文章

1. [解释器](./interpreter.md)：编程语言的本质、编译器与解释器的区别、Python 解释器种类与安装方式。
2. [Python 高阶数据结构](./datastruct.md)：List、Tuple、Set、Dictionary 四大内置数据结构，与 Java 的 ArrayList、HashSet、HashMap 一一对应。
3. [面向对象编程](./objectOriented.md)：类与对象、封装、继承、多态、特殊方法，对比 Java 的 private、extends、接口与鸭子类型。
4. [Python 函数](./function.md)：函数定义与返回值、位置参数、默认参数、`*args`、`**kwargs`、关键字专用参数与解包调用，对比 Java 的方法重载、可变参数与 Map 传参。

## 建议阅读顺序

1. [解释器](./interpreter.md)：先了解 Python 如何运行，搭建好环境。
2. [Python 高阶数据结构](./datastruct.md)：掌握最常用的数据组织方式。
3. [面向对象编程](./objectOriented.md)：进阶到类与对象，构建可复用的代码结构。
4. [Python 函数](./function.md)：掌握参数传递的完整用法，写出灵活可复用的代码。

> 后续将陆续补充：变量与数据类型、流程控制、文件读写、异常处理、常用标准库与第三方库（pip）等。
