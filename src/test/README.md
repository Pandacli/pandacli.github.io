# 软件测试基础

软件测试的入门与进阶，都绕不开这四个模块：**测试基础、需求分析、用例设计、缺陷管理**。它们构成了测试工程师的基本功，也是面试与日常工作中最常被追问的部分。

- **测试基础**：测试的定义、测试流程、测试类型、测试方法（黑盒/白盒/灰盒）与测试生命周期模型。
- **需求分析**：如何读懂需求、挖掘隐性需求、需求评审、测试需求拆解与需求跟踪矩阵。
- **用例设计**：等价类划分、边界值、判定表、因果图、场景法、正交实验等经典用例设计方法。
- **缺陷管理**：缺陷生命周期、缺陷报告规范、缺陷定位与分析、缺陷度量与质量评估。

## 适合谁看

- 刚入行、想系统补齐测试理论基础的测试新人。
- 准备软件测试岗位面试、需要复习基础知识的同学。
- 从功能测试向自动化测试 / 测试开发转型，需要回炉理论基础的工程师。
